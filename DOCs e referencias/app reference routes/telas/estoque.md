# Tela de Estoque (Principal)

**Arquivo:** `tela de estoque.png`

## Objetivo
Exibir os atalhos de gerenciamento e movimentação de inventário físico, tais como auditorias de estoque, emissão/recebimento de notas fiscais e entradas manuais de produtos.

## Hierarquia Visual
1. Barra superior com botão de voltar e título ("Estoque").
2. Lista vertical de links para as subseções de inventário.

## Seções
- **Navegação de Inventário:** Lista de acessos às funcionalidades internas do controle de estoque.

## Componentes
- **Action Link List:** Menu vertical composto por ícone e texto do link.

## Campos
- Nenhuns.

## Botões
- **Voltar (seta esquerda):** Retorna ao Dashboard principal.
- **Balanço de estoque:** Link de atalho para auditoria de inventário.
- **Notas fiscais:** Link de atalho para gerenciamento de documentos fiscais de entrada/compra.
- **Entrada manual:** Link de atalho para movimentações diretas e manuais do estoque.

## Navegação Identificável
- Seta superior esquerda retorna para o **Dashboard**.
- "Balanço de estoque" direciona para a **Tela de Balanço de Estoque**.
- "Notas fiscais" direciona para a **Tela de Notas Fiscais**.
- "Entrada manual" direciona para a **Tela de Entrada Manual de Estoque**.

- Nenhuns.

- A tela apresenta um design limpo e de navegação direta.
